# Мониторинг ЭТрН (Контур.Логистика) → MAX + Google Sheets

Прототип под заказ: система следит за статусами электронных транспортных
накладных и шлёт уведомления в мессенджер MAX, когда участник подписал титул
или когда документ «висит» дольше порога.

## Что уже работает (демо-режим)

```
python monitor.py --demo
python monitor.py --report
```

На встроенных фикстурах показывает: подпись каждого титула → уведомление;
накладная старше `STALE_HOURS` (по умолчанию 4 ч) с неподписанным титулом →
напоминание «кого пнуть». Состояние хранится в `state.json` — дублей нет.

`--report` шлёт дайджест точно по формату заказчика: список накладных,
кто ещё не подписал и сколько часов висит документ (🔴 > STALE_HOURS).

## Боевой режим

- `KONTUR_API_KEY`, `KONTUR_ORG_ID` — ключи API Контур.Логистики
  (поля `normalize_etn()` подгоняются под реальный ответ за 10 минут после
  первого живого запроса).
- `MAX_BOT_TOKEN`, `MAX_CHAT_ID` — бот MAX (Bot API, аналог telegram-ботов).
- `GOOGLE_SA_JSON`, `SHEET_ID` — таблица Google Sheets с одной строкой на ЭТрН
  (✓/— по титулам). `pip install gspread google-auth`.
- `POLL_SECONDS` — интервал опроса (300 с по умолчанию).

## Этап 2 (по ТЗ заказчика)

- Реестр накладных и счетов: завершённая ЭТрН → строка «можно выставлять счёт».
- Дайджест в конце дня вместо мгновенных пингов (настройка).
- Права: несколько сотрудников в одном чате MAX.
